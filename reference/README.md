# Golden reference files

Put `.kmz` files created by DJI Fly on the RC 2 here (from
`Android/data/dji.go.v5/files/waypoint/<UUID>/<UUID>.kmz`), plus any other file found in the
same mission folder.

The WPML exporter is derived from and tested against these files. It will not be implemented
while this folder holds no `.kmz`.
