# Waypoint Planner

Local-first web app to plan DJI Air 3S waypoint missions and export them as DJI WPML `.kmz`
files for side-loading into DJI Fly. See `SPEC.md`.

```sh
npm install
npm run dev      # dev server
npm test         # unit tests
npm run build    # static build in dist/
npm run preview  # serve dist/ locally
```
